# ผลการตรวจเวอร์ชันแรก

ตรวจบน Windows PC เครื่องพัฒนาวันที่ 31 ตุลาคม 2026 ด้วย Eclipse Temurin JDK 21.0.13

- คอมไพล์ Source Code ด้วย `--release 21` และสร้าง Executable JAR ผ่าน
- `GameRulesTest`: ผ่าน 9,752 จุดตรวจ ส่วนใหญ่เป็นการตรวจซ้ำใน Simulation ไม่ใช่กรณีทดสอบอิสระทั้งหมด
- จำลองบอตเล่น 10 นาที ตรวจคะแนน เกราะ คำไม่ซ้ำ และขอบเขตจำนวนศัตรูผ่าน
- จำลองไม่โจมตีจน Game Over และตรวจว่ารอบใหม่เริ่มสถานะใหม่ผ่าน
- บันทึกคะแนน เปิดอ่านใหม่ ข้อมูลเสีย และพาธบันทึกที่ใช้ไม่ได้ผ่าน
- `UiSmokeTest`: ทดสอบ Event ของ Start, Pause, Resume, Enter, Game Over และ Play Again ผ่าน
- ตรวจภาพ Menu, Gameplay, Pause, Game Over และ Menu ที่ขนาดหน้าต่างต่ำสุดแล้ว
- เปิดหน้าต่างจาก JAR จริงได้ และทดสอบ Swing อีกครั้งโดยใช้ Classpath จาก JAR ในโฟลเดอร์อื่นผ่าน
- PDF รายงาน 9 หน้าได้รับการเรนเดอร์และตรวจภาพทุกหน้าแล้ว

รันการทดสอบกติกาซ้ำด้วย `test.ps1` การตรวจ Swing ใช้คำสั่งด้านล่างหลังจากรัน test.ps1 แล้ว โดยกำหนด user.home เป็นโฟลเดอร์ทดสอบในโปรเจกต์เพื่อไม่แตะคะแนนจริง:

```powershell
java "-Duser.home=$PWD\build\ui-profile" -cp "build\classes;build\test-classes" typestrike.UiSmokeTest
```

UiSmokeTest สร้างภาพใน build/ui-review และไม่เปิดหน้าต่างหรือย้าย Focus ของผู้ใช้

ยังไม่ได้ทดสอบบน Notebook ของผู้จัดทำ ไม่ได้วัดความสนุกหรือความยากจากกลุ่มผู้เล่น และไม่ได้ยืนยันว่าตรงตามความหมายของคำว่าอุปสรรคที่อาจารย์ต้องการทั้งหมด ต้องใช้การทดลองเล่นและข้อคิดเห็นเพิ่มเติมก่อนส่งจริง
